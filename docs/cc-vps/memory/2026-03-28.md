## Probleemid ja lahendused
- Medusa otsib medusa-config.js (mitte .ts) — lõin JS versiooni
- next.config.ts i18n ei toeta App Router — eemaldasin, i18n hiljem [locale] kaudu
- Node.js URL localhost -> IPv6 ECONNREFUSED — muutsin 127.0.0.1-ks
- Handle'ites topelt sidekriipsud -- — lisasin replace(/-{2,}/g, "-")
- Bash history expansion muudab ! märki paroolides — kasuta JSON faili + -d @file
- Docker Alpine ei sisalda curl — kasuta wget healthcheck'ides
