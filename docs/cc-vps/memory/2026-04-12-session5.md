# XL Sessioonilogi 2026-04-12 (session 5)

## Tehtud

### EN storefront UX
- Esilehe L1 kategooriad laiendatud kogu VEVOR orderi peale, mitte ainult 10 kategooriat
- Best Sellers / New Arrivals sektsioonid eraldatud tugevama borderi, varju ja card-lay-out'iga
- Product cardi hover actions:
  - compare ikoon viidi südame kõrvale thumbnail view's
  - compare state kuvatakse badge'ina
- Tootelehele lisatud wishlist + compare tegevused üheks komponendiks
  - compare state korral näitab `Vaata võrdlust`

### Breadcrumb / layout shift
- Tootelehe breadcrumb reserveerib rohkem ruumi ja on flex-režiimis, et vähendada hüpet
- Search breadcrumbile lisatud sama reserveeritud kõrgus ja sujuvam välimus
- Kategoorialehele lisatud sama breadcrumb-stiil

### Search results UX
- Otsingu tulemuste leht ümber struktureeritud summary-kaardiks + tulemuste paneeliks
- Toodete arv on nüüd eraldi badge'ina nähtav
- Kategooria- ja soovituspõhised chipid eraldatud oma blokki
- Search filters said uue `Smart filters` / `Nutifiltrid` dropdown'i

### Adaptive filters
- MeiliSearch indeksisse lisatud `spec_filters`
- Indexed spec-facetid ehitatakse metadata + description key:value paaridest
- Search/category lehed saavad nüüd `spec_filters` facetid ja URL param'i
- Filtrid toetavad esimest generilist adaptive-filter kihti ilma tootetüübi hardcode'ita
