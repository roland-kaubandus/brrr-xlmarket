### 🔑 Juurpõhjus — admin 502 + storefront katki
**Coolify-hallatud `medusa` teenus oli asendatud käsitsi konteineriga `medusa-xlmarket-fixed`.** Taasloomisel kadusid:
1. Traefik labelid → `api.xlmarket.ee` router'il pole backend'i → **503**
2. võrgu-alias `medusa` → storefront `medusa:9000` = `bad address` → SSR/hinnad katki (`[getProduct] fetch failed`, `price enrichment failed`)

Meili `meili:7700` timeoutid logides olid **vahelduvad** (meili külm/koormatud), mitte konfiguratsiooniviga — `MEILISEARCH_HOST=http://meili:7700` oli juba seatud.

## Gotchas (uued)

- **Medusa admin URL on `api.xlmarket.ee/app`** (SERVICE_FQDN_MEDUSA=api.xlmarket.ee), aga käsitsi yaml lisas ka `admin.xlmarket.ee`. Coolify-hallatud router = api.xlmarket.ee (503 sest backend gone), käsitsi router = admin.xlmarket.ee
- **`medusa-xlmarket-fixed`** = käsitsi taasloodud Coolify konteinerist (image `uo28..._medusa:7402b8f7`), kaotas labelid + aliase. coolify-proxy on 7 võrgus, sh `uo28...` → resolvib konteineri-nimesid
- **order-shipped.ts murd** = ESM `.js` extension puudus importis, MITTE päris "module resolution broken"
- Remote on `origin` (github roland-kaubandus/brrr-xlmarket), MITTE `roland` nagu vana CLAUDE.md väidab
- mailcow hostil teenib ainult `xlrent.eu` — xlmarket meil käib SMTP relay kaudu
