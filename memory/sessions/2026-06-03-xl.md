## Email — täielik diagnoos + Mailcow relay seadistus

**Leid:** jooksval medusa konteineril POLNUD ühtegi SMTP env'i → kood langes `127.0.0.1:25` (konteinerisisene, suletud) → **kõik emailid ebaõnnestusid vaikselt** (tellimuse kinnitus, arve, admin, tarne).

**DNS faktid:**
- xlmarket.ee MX = Elkdata (mh7/mh9.elkdata.ee), NS = ns.elkdata.ee (veebimajutus.ee paneel = Elkdata teenus)
- SPF = `v=spf1 a mx include:mail.spf.elkdata.ee ~all` (EI luba mail.xlrent.eu)
- DMARC = `p=none` (olemas)
- mailcow siin hostil = ainult `xlrent.eu` (mail.xlrent.eu = 65.21.126.235)

**Risto → tarmo asendus (commit `9382dac5`):** kõik `risto.oitmaa@gmail.com` + `risto@brrr.ee` → `tarmo@naissaar.eu` (EMAIL_INVOICE, RISTO_ADMIN_EMAIL value, email.ts/.js, session16 log). SSH `risto@65.21.126.235` JÄETI puutumata (pole email). DB oli risto-vaba.
- ⚠️ `docs/cc-vps/memory/2026-04-10.md`: "admin@xlmarket.eu → risto gmail" forwarding seadistatud Elkdata's — vaja Elkdata paneelis muuta (mitte repos).

**Mailcow smarthost relay (test ÕNNESTUS 2026-06-03, commit `47fa493a`):**
- Tee: medusa → mail.xlrent.eu:587 (auth `server@xlrent.eu` / `AinultRahu6029`) → relay → Elkdata. `status=sent` tarmo@naissaar.eu jaoks ✅
- **Mailcow sender_acl** (live, püsiv): `server@xlrent.eu` → send_as `info@xlmarket.ee` external=1. (Ilma selleta `553 Sender address rejected`.)
- **Võrk:** medusa ei jõudnud relayni (10.0.6.1 timeout) → liidetud `mailcowdockerized_mailcow-network`'i. Compose'is external network + fallback runbook'is.
- **TLS:** relay self-signed → `email.ts/.js tls.rejectUnauthorized=false` (override `SMTP_TLS_REJECT_UNAUTHORIZED=true`)
- **Env saatjad:** From `info@xlmarket.ee`, admin+arved `tarmo@naissaar.eu`
- **EI aktiveeritud live'is** — jooksval medusa konteineril pole veel env'i/uut buildi. Aktiveerub **Variant 2 redeploy'l** (kasutaja otsus, ära taasloo konteinerit praegu).

**DNS vaja (kasutaja, Elkdata/veebimajutus.ee):** SPF → `v=spf1 a mx include:mail.spf.elkdata.ee a:mail.xlrent.eu ~all`. DKIM hilisem.

## Gotchas (email)
- Medusa konteiner ei jõua hostimailcow'ni gateway (10.0.6.1) ega avaliku IP kaudu — VAJA liita `mailcowdockerized_mailcow-network`'i, siis mail.xlrent.eu:587 töötab (hairpin läbi mailcow-net gateway 172.22.1.1)
- mailcow keeldub võõra domeeni From'ist kuni sender_acl (external=1) lisatud
- xlmarket.ee EI tohi lisada mailcow täisdomeenina (MX=Elkdata → lõhuks sissetuleva posti)
