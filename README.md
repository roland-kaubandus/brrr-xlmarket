# brrr-xlmarket

**xlmarket.eu** — VEVOR toodete e-pood Eestis.

Tellija: Roland Kaubandus OÜ | Kontakt: Tarmo

## Stack

- Medusa.js 2.0 (backend)
- Next.js 15 + Tailwind (storefront)
- PostgreSQL 16 + Redis 7
- Docker Compose

## Quick start

```bash
cp .env.example .env
# seadista .env väärtused
docker compose up -d
```
